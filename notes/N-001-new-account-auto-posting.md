# N-001 · 신생 계정에 자동 게시를 서둘렀다가 정지된 이야기

표시: **실패 노트 (실제 경험)**

## 무슨 일이 있었나
새로 만든 SNS 계정에 카드 이미지 형태의 게시물을 자동으로 연속 올렸습니다. 며칠 만에 계정이 규정 위반으로 영구 비활성화됐고, 이의 제기는 받아 주지 않았습니다.

## 추정 원인 (검증하지 못함)
신생 계정의 짧은 기간 연속 게시와 같은 시기의 계정 보안 이벤트가 겹쳐 자동화로 판정됐을 가능성이 있습니다. 하루 상한을 낮게 잡았지만 상한은 안전선이 아니었습니다.

## 바꾼 것
- 새 계정은 서두르지 않습니다.
- 처음 2주는 사람이 직접 올리고, 이후에도 하루 1건 이하로 시작합니다.
- 반응 숫자보다 계정 상태를 먼저 봅니다.

## 남긴 장치
비상 정지 스위치, 이중 확인, 사람 승인 없이는 재개하지 않는 규칙.

## 한계
한 번의 사례라 일반화할 수 없습니다.
