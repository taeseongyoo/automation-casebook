# automation-casebook

멈출 곳을 먼저 설계하는 업무 자동화 사례집입니다. 실제로 해 본 것과 실패한 것만 씁니다.

## 원칙
- **사람이 확인하는 지점**을 모든 사례에 적습니다. 돈·서류·외부 발신이 얽힌 일은 자동으로 끝내지 않습니다.
- **멈추면 멈췄다고 알립니다.** 조용히 실패하는 자동화는 쓰지 않습니다.
- 가상 사례에는 성과 숫자를 쓰지 않습니다. 실제 적용 후에만 측정값을 적습니다.
- 이름·위치·계정·내부 자료 등 식별 정보는 싣지 않습니다.
